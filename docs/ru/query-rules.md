# Alcedo: как писать запросы

Alcedo превращает список поисковых запросов в DOI, сгруппированные по запросам.
Подробности об установке и источниках — в [README на английском](../../README.md).

Быстрый старт:

```bash
pip install .
alcedo
```

Программа читает `queries.txt` из текущей папки и пишет результат в `alcedo_results.txt`.
Существующий файл результатов она не заменит: продолжить его можно через `--resume`, начать заново через `--overwrite`.

Один и тот же запрос может уйти в Google Scholar или в OpenAlex, поэтому пишите его так,
чтобы он работал в обоих. Поведение OpenAlex и число найденных работ проверены на реальном API в октябре 2026.
Пределы с пометкой «эмпирически» — это совет, а не результат измерений.


## 1. Файл с запросами

- Запросы разделяются точкой с запятой `;`. Удобный стиль: один запрос на строку, в конце `;`.
- Перенос строки внутри запроса превратится в пробел.
- Символ `;` внутри запроса ставить нельзя, даже в кавычках: он разрежет запрос на два.
- Комментариев нет: строка с `#` станет частью запроса.
- Одинаковые запросы выбрасываются автоматически.
- Сохраняйте файл в кодировке UTF-8 (Блокнот: «Сохранить как» → «Кодировка: UTF-8»).


## 2. Язык — только английский

Базы почти полностью англоязычные: «перламутр» находит в OpenAlex 175 работ, а `nacre` — 17 274.
Пишите термины так, как их пишут в статьях. Варианты написания объединяйте через OR: `(aluminium OR aluminum)`.


## 3. Синтаксис

| Что нужно | Как писать | Пример |
|---|---|---|
| Все слова сразу (И) | через пробел | `nacre toughness` |
| Точная фраза | в прямых кавычках `"…"` | `"brick-and-mortar"` |
| Любой из вариантов (ИЛИ) | `(A OR B)` — OR заглавными, всегда в скобках | `(micropillar OR "hierarchical microstructure")` |
| Исключить слово | минус слитно со словом, перед минусом пробел | `-dental` |

Где легко ошибиться:

- `or` строчными — не оператор. `nacre or toughness` молча означает «И»: 4 696 работ,
  а `nacre OR toughness` — 780 771.
- OR нужны скобки. `nacre toughness OR fracture` нашёл 17 274 работы, столько же, сколько один `nacre`,
  а `nacre (toughness OR fracture)` — 6 157.
- OpenAlex сам минус не понимает, поэтому Alcedo заменяет его на `NOT`. Дефис внутри слова безопасен:
  `mussel-inspired`, `Ti-6Al-4V`.
- Кавычки нужны прямые `"`. «Ёлочки» не работают.
- Спецсимволы в терминах допустимы: `Ti-6Al-4V`, `β-cyclodextrin`, `Ti/TiN`, `Li+`.


## 4. Чего не писать

| Не пишите | Почему |
|---|---|
| Звёздочку `*` (`nacre*`) | OpenAlex вернёт ошибку, и запрос останется без результатов. |
| `intitle:`, `author:`, `source:` | Понимает только Scholar. Для OpenAlex префикс отбрасывается, и слово ищется везде. |
| `site:`, `filetype:`, годы (`2020-2024`) | Это не фильтры: годы просто станут лишними словами поиска. |
| Слово `review`, чтобы найти обзоры | Найдёт статьи, где встречается это слово. |
| 1–2 общих слова (`biomaterials`) | 50 результатов будут почти случайными. |
| Две темы в одном запросе | Разбейте на два запроса. |
| Длинные списки OR | Размывают выдачу. Эмпирически: до 4–5 вариантов. |
| Очень длинные запросы | Эмпирически: до 10–12 значимых слов. |


## 5. Как построить хороший запрос

Формула: **объект + ключевая структура или механизм в кавычках + класс материала или метод + свойство или задача.**

```text
biomimetic nacre   ("brick-and-mortar" OR "layered structure")   composite   fracture toughness
```

- Эмпирически: 2–4 смысловых блока, каждый блок — слово, фраза или группа OR.
- Самый специфичный термин ставьте в кавычки: фраза отсекает статьи, где её слова стоят порознь.
- Исключайте известный шум. OpenAlex ищет и по полным текстам, поэтому общие слова цепляют статьи, где они
  упомянуты мимоходом. В одном тесте запрос про полидопамин попал в тему только на 46%: туда набилась стоматология.
  Помогает `mussel-inspired polydopamine "wet adhesion" -dental -periodontal`.
- Узкий запрос — это нормально: Alcedo берёт до 50 работ, а если их меньше, то все.


## 6. Примеры

```text
biomimetic nacre ("brick-and-mortar" OR "layered structure") composite fracture toughness;
gecko-inspired dry adhesive (micropillar OR "hierarchical microstructure") adhesion;
bioinspired superhydrophobic surface "lotus effect" self-cleaning;
"selective laser melting" ("Ti-6Al-4V" OR "titanium alloy") porosity "process parameters";
"higher heating value" biomass correlation "ultimate analysis";
"genetic algorithm" ("inverse design" OR "molecular design") polymer;
```


## 7. Порядок и лимиты

- Важные запросы ставьте в начало: они успеют пройти, пока не кончилась квота.
- SerpApi, бесплатный тариф: на момент написания 250 поисков в месяц и 50 в час. Запрос на 50 результатов
  стоит 3 поиска, то есть около 16 запросов в час и 80 в месяц. Запрос до 20 результатов стоит 1 поиск.
- OpenAlex: на момент написания около $0.10 в день без ключа и $1 с бесплатным ключом (примерно 1000 поисков).
  При превышении он отвечает `429`: Alcedo повторит запрос, а затем сообщит об этом.


## 8. Как проверить запрос и команды

Первые 10 результатов через OpenAlex, за секунды:

```bash
alcedo --source openalex --pages 1 -i test.txt -o test_results.txt --overwrite
```

Если выдача уходит не туда, добавьте фразу в кавычках или исключение.

```bash
alcedo                     # обычный запуск
alcedo --resume            # продолжить после сбоя
alcedo --overwrite         # заменить файл результатов и собрать всё заново
alcedo --serpapi-key КЛЮЧ  # Scholar через SerpApi (лучше задать переменную SERPAPI_KEY)
alcedo --redo-openalex     # пересобрать блоки из OpenAlex, например после обновления квоты SerpApi
alcedo --pages 3           # брать до 3 страниц (30 результатов) вместо 5
alcedo --help              # все параметры
```

Блоки, в которых есть результаты OpenAlex, помечены строкой `Source: OpenAlex`.
